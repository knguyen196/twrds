# TWRDS

**A nudge in the right direction.**

TWRDS is a conversational decision-making app that helps you think through decisions clearly. It guides you through a short context-setting flow, has a real conversation with you about your situation, then delivers a structured analysis — pros, cons, insights, and a recommendation — with a confidence rating.

---

## Features

- **Guided pre-chat** — set emotional state, stakes level, and decision type before the conversation starts
- **AI chat** — a warm, conversational assistant that asks the right questions
- **Structured analysis** — confidence ring, pros/cons breakdown, insights, and a clear recommendation
- **Past decisions** — saved locally, viewable and resumable at any time
- **Follow-up conversations** — revisit and build on past decisions
